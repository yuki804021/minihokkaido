# Mini Hokkaido 3D

[Mini Tokyo 3D](https://minitokyo3d.com/) を参考にした、**札幌を中心とした北海道の鉄道の 3D 可視化**のプロトタイプです。
3D 地図の上を列車が時刻に合わせて走ります。

[Mini Shikoku 3D](https://github.com/marui-takeru/minishikoku3d)（四国版）をもとに、地図の範囲と路線データを北海道に入れ替えたものです。

- 札幌市営地下鉄（南北線・東西線・東豊線）、札幌市電（ループ線の外回り・内回り）、函館市電（2 系統・5 系統）
- JR 北海道の普通・快速（快速エアポート、はこだてライナーなど）と主な特急（北斗、すずらん、ライラック・カムイ、宗谷、サロベツ、オホーツク、大雪、おおぞら、とかち）
- 北海道新幹線 はやぶさ（新函館北斗〜新青森）、道南いさりび鉄道
- 主なフェリー（津軽海峡フェリー・青函フェリー、シルバーフェリー、さんふらわあ・太平洋フェリー、新日本海フェリー、ハートランドフェリー、羽幌沿海フェリー）
- 都市間高速バス（札幌〜函館・旭川・釧路・帯広・稚内・根室など 94 系統）を時刻表データどおりに運行。路線バス（コミュニティバス・デマンド交通を除く）は路線図と停留所を表示し、停留所をクリックすると時刻表（この先の発車時刻）を表示（バスは動かさない）
- 道内 12 空港と、空港の利用状況（国の統計）、航空便（推計）。道外便のほか、丘珠・新千歳などを結ぶ道内便は離陸から着陸まで 1 本の経路で飛ぶ

## 使い方

ビルドは不要です。自分のパソコンで簡易サーバを起動して、ブラウザで開きます。

1. **リポジトリを手元に用意する**。どちらか一方で構いません。
   - かんたんな方法: GitHub で `yuki804021/minihokkaido` を開き、緑の「Code」ボタンから「Download ZIP」を選んで、ダウンロードした ZIP を展開します。
   - git を使う方法: `git clone https://github.com/yuki804021/minihokkaido.git` を実行します。
2. **ターミナルを開く**。
   - Windows: スタートメニューから「PowerShell」を開きます。
   - Mac: 「ターミナル」を開きます。
3. **展開したフォルダに移動する**。`index.html` が入っているフォルダです。

   ```sh
   cd ダウンロード先のパス/minihokkaido
   ```

   `cd ` と入力したあと、フォルダをターミナルにドラッグ＆ドロップすると、パスが自動で入ります。
4. **サーバーを起動する**。

   ```sh
   python3 tools/serve.py
   ```

   Windows で `python3` が見つからないと言われたら、`python tools\serve.py` か `py tools\serve.py` を試してください。
   「Mini Hokkaido 3D: http://localhost:8000/ を開いてください」と表示されて止まったように見えますが、これで起動しています。このターミナルは閉じずに置いておいてください。
   `python3 -m http.server 8000` で起動しても見られますが、その場合は「実際の飛行機」（下の表）だけが使えません。
5. **ブラウザで開く**。Chrome や Edge などのブラウザを開き、アドレス欄に `http://localhost:8000/` と入力して Enter を押します。
   地図と路線、「Mini Hokkaido 3D」のパネルが表示されれば成功です。
6. **実際の飛行機を見る**（任意）。左のパネルの「表示」の欄にある「実際の飛行機」を押すと、今実際に飛んでいる飛行機がオレンジ色で表示されます。
   時計が「実時間」で現在時刻のときだけ表示されます（時刻を指定したり倍速にしたりしたときは、「現在時刻」を押すと戻ります）。
7. **終わるとき**は、ターミナルで `Ctrl + C` を押します。

うまく表示されないとき:

- ファイルの一覧が表示される: ZIP を展開すると、フォルダの中にもう 1 つ同じ名前のフォルダができることがあります。`Ctrl + C` でサーバーを止め、`index.html` があるフォルダに移動してから起動し直してください。
- 「このサイトにアクセスできません」と出る: `https://` ではなく `http://` で入力しているか確認してください。それでも開けなければ `http://127.0.0.1:8000/` を試してください。
- `index.html` をダブルクリックして直接開く方法では動きません（データの読み込みがブラウザに止められるため）。必ずサーバーを経由してください。
- 地図の背景と地図ライブラリはインターネットから読み込むので、ネットにつながった状態で開いてください。
- 「実際の飛行機」を押すと「tools/serve.py で起動してください」と出る: `python -m http.server` で起動しています。`Ctrl + C` で止めて、手順 4 の `tools/serve.py` で起動し直してください。
- 「実際の飛行機」をオンにしても飛行機が出ない: 深夜・早朝は北海道の上空に飛行機がほとんどいません。パネルの説明に「0 機を表示中」と出ていれば正常です。「取得できません」と出るときは、インターネットの接続を確認してください（10 秒ごとに自動で再試行します）。
- 表示が古いまま変わらない: ブラウザが古いファイルを覚えていることがあります。`Ctrl + F5`（Mac は `Cmd + Shift + R`）で再読み込みしてください。

### 最新版に更新する

GitHub の最新版に更新するときは、最初に用意した方法に合わせて次のどちらかを行います。どちらも、先にターミナルで `Ctrl + C` を押してサーバーを止めておきます。

- **ZIP で用意した場合**: 手順 1 と同じく「Download ZIP」で最新版をダウンロードし、展開したフォルダを古いフォルダと入れ替えます（古いフォルダは削除するか、名前を変えて残します）。
  `tools/cache/`（ダウンロードしたデータの保存先）は ZIP に含まれないので、入れ替えても困ることはありません。
- **git で用意した場合**: ターミナルで、手元のフォルダに移動してから `git pull` を実行します。

  ```sh
  cd ダウンロード先のパス/minihokkaido
  git pull
  ```

  「Already up to date.」と出れば、すでに最新です。
  自分でファイルを書き換えていて `git pull` が止まる（「Your local changes ... would be overwritten」と出る）ときは、書き換えを捨ててよければ次で GitHub の状態にそろえられます。書き換えた内容は消えるので注意してください。

  ```sh
  git fetch origin
  git reset --hard origin/main
  ```

更新したら、手順 4〜5 と同じように起動してブラウザで開きます。ブラウザの表示が古いままなら `Ctrl + F5` で再読み込みしてください。

ZIP で用意していて、これから git に切り替えたい場合は、[Git for Windows](https://gitforwindows.org/) などで git を入れてから、新しいフォルダに `git clone` します（手順 1 の git を使う方法）。
リポジトリが非公開のときは、初回にブラウザで GitHub へのサインインを求められます。

### 画面の操作

| 操作 | 内容 |
| --- | --- |
| 列車をクリック | 系統・行先と、この先の停車駅・到着予定の一覧を表示。「追跡」でカメラが追従 |
| 駅をクリック | その駅の発車案内（この先の発車時刻・系統・行先）を表示。函館市電の電停と高速バスの停留所は時刻表データどおりの時刻、それ以外は推計ダイヤの時刻 |
| バス停をクリック | 路線バスの停留所（地図を拡大すると茶色の丸で表示）の時刻表を表示。この先 3 時間の発車時刻・系統・行先と、事業者・路線名。平日／土曜／日祝のダイヤは日付と「平日ダイヤ／土休日ダイヤ」の切り替えに合わせる。函館バス・JR 北海道バス・北海道北見バス・阿寒バス・拓殖バスなど、時刻表データの無い事業者の停留所は路線名のみ |
| 駅をさがす | 駅名や空港名を入力するとその場所へ移動し、発車案内（空港なら利用状況）を表示。「新千歳空港」は駅と同じ名前なので JR の駅が開きます。空港の統計は地図上の空港の印をクリックしてください |
| 空港をクリック | 滑走路・運用時間、2025 年の乗降客数（国内線・国際線）・着陸回数、月別のグラフ、2016〜2025 年の推移（「表で見る」で表）、まもなく出発／到着する便（推計）。空港の印の大きさは年間の乗降客数に比例 |
| 到達圏 | 発車案内の「ここから行ける範囲（到達圏）を表示」で、その時刻に出発して各駅へ最短何分で着けるかを 5 段階で色分け表示。上限は 30/60/90 分から選択でき、「今の時刻で再計算」で時間帯ごとの比較ができる |
| 実際の飛行機 | 「表示」の欄のボタンでオン／オフ。ADS-B のオープンデータ（adsb.lol）で、今実際に飛んでいる飛行機を画面の範囲に表示する（10 秒ごとに更新、その間は速度と向きから位置を補間）。機体をクリックすると便名・機材（例: B738）・機体番号・高度・速度と、空港の近くなら使用滑走路（推定）を表示。空港のカードには、直近 10 分に離着陸した便から推定した使用滑走路が出る。時計が「実時間」で現在時刻のときだけ表示され、その間は推計の航空便を隠す。`tools/serve.py` で起動したときだけ使える |
| 平日ダイヤ / 土休日ダイヤ | 押すと切り替え。最初は今日の日付（土日・祝日かどうか）で決まる。時刻表データで走る函館市電のダイヤが変わる（推計ダイヤの路線は変わらない） |
| 実時間 / ×10 / ×60 / ×300 | 時間の進み方を変更 |
| 時刻入力 | 任意の時刻へジャンプ (例: 朝ラッシュ 07:45) |
| エリア | 札幌中心部・すすきの・札幌近郊・新千歳空港・小樽・旭川・函館・釧路・津軽海峡・稚内／利尻／礼文・北海道全体へ移動 |
| 路線 | 事業者・種別ごとの表示切り替え |
| 1日の運行本数 | 表示中の路線について、時刻ごとの運行中の列車本数をグラフ表示。ホバーで値、クリックでその時刻へ移動。「表で見る」で 1 時間ごとの表 |
| 表示 | 地図の昼夜（自動・ライト・ダーク）、3D 建物、地形 (標高) |
| 撮影モード | パネルを隠してカメラをゆっくり回転（動画・GIF 撮影用）。Esc で終了。`?cinema` でも起動 |
| この景色を共有 | 今の時刻・倍速・カメラ位置を含むリンクをコピー |
| キー操作 | Space 一時停止、1〜4 倍速、N 現在時刻、C 撮影モード、F 追跡、Esc 閉じる |

URL パラメータ: `?t=07:45` (開始時刻), `?speed=60`, `?view=hakodate`, `?day=weekday` / `?day=holiday` (平日／土休日ダイヤを指定), `?theme=light` / `?theme=dark` (昼夜の自動切り替えを止める), `?terrain`, `?cinema`（撮影モード）

例: `http://localhost:8000/?view=hakodate&t=08:00&day=holiday`（函館を土休日の朝 8 時から表示）

`?view=` に使える値: `sapporo` `susukino` `sapporo_wide` `new_chitose` `otaru` `asahikawa` `hakodate` `kushiro` `seikan` `wakkanai` `hokkaido`

## 構成

```
index.html              画面
css/style.css
js/sim.js               運行シミュレーション (時刻 → 列車位置)
js/app.js               地図・描画・UI (MapLibre GL JS)
data/network.js         路線・駅・運行パターン (自動生成)
tools/build_network.py  data/network.js を作るスクリプト
tools/serve.py          手元で開くための簡易サーバ (実際の飛行機のデータも中継する)
tools/build_bus.py      路線バスの路線図・停留所・時刻表 (data/bus_map.js, data/bus/) を作るスクリプト
data/bus_map.js         路線バスの路線図・停留所 (自動生成)
data/bus/*.json         路線バスの時刻表 (事業者ごと。停留所をクリックしたときに読み込む)
```

- 地図: [MapLibre GL JS](https://maplibre.org/) + [OpenFreeMap](https://openfreemap.org/) (OpenStreetMap ベース、API キー不要)。
  読み込めない場合は国土地理院の淡色地図に切り替わります。
- 地形: AWS Terrain Tiles (Terrarium)
- 列車は `fill-extrusion` で車体・窓・屋根を積み重ねて描画し、ズームアウト時は見やすいよう大きさを誇張しています。
- 光の向きと空の色は、シミュレーション時刻の太陽の位置（札幌付近）に合わせて朝・昼・夕・夜と変化します。
- 始発駅では発車の数分前から列車がホームで待機します。
- 日没後は地図が夜のデザインに切り替わり、列車の前照灯と尾灯が灯ります（「地図: 自動（昼夜）」のとき）。

使っているデータの一覧と、実データ・推計の区別は [DATA_SOURCES.md](DATA_SOURCES.md) に、更新履歴は [CHANGELOG.md](CHANGELOG.md) にまとめています。

### 路線データの作り直し

路線・運転間隔・停車駅・フェリー・空港の設定は `tools/build_network.py` にまとめてあります。編集したら次のコマンドで `data/network.js` を作り直します。

```sh
python3 tools/build_network.py
```

初回は駅データ（駅データ.jp、GitHub 経由）、国土数値情報（鉄道データ 約 13MB・空港データ）、空港管理状況調書（Excel）、函館市電の時刻表データをダウンロードして `tools/cache/` に保存します。
空港管理状況調書の読み込みには `openpyxl` が必要です（`pip install openpyxl`）。
駅の位置はそれぞれ国土数値情報の駅（ホームの中点）に合わせ、駅と駅の間は国土数値情報の線路網の最短経路でつないでいます（路線の長さは営業キロとほぼ一致します）。
都市間高速バスの経路は、停留所を OpenStreetMap の道路に沿ってつないだもので、OSRM の公開サーバに問い合わせた結果を `tools/cache/osrm/` に保存します（初回は 1 秒に 1 回ずつ問い合わせるので、2〜3 分かかります）。

路線バスの路線図・停留所・時刻表は、別のスクリプトで作ります。

```sh
python3 tools/build_bus.py
```

時刻表は「次の平日・土曜・日祝」に走る便を取り出して保存するので、ダイヤ改正があったときや、しばらくたって季節ダイヤが変わったときは、`tools/cache/` の時刻表データ（`hoda_*.zip`・`tokachi_*.zip`・`nemuro_bus.zip`、高速バスは `hoda_highway_bus.zip`）と `hoda_gtfs_package.json` を消してから、`build_bus.py` と `build_network.py` の両方を実行し直してください。
北海道オープンデータプラットフォームは、利用前に[利用目的のフォーム](https://forms.gle/BhaWhWDUqnwm8WHq9)への記入をお願いしています。

#### 函館市電のダイヤ改正があったとき

函館市電の時刻表データ（GTFS）は `tools/cache/hakodate_tram_gtfs.zip` に保存したものを使い続けます。ダイヤ改正があったら、このファイルを消してから作り直すと、最新のデータで作り直せます。

```sh
rm tools/cache/hakodate_tram_gtfs.zip
python3 tools/build_network.py
```

ダウンロードの URL は改正ごとに変わるため、スクリプトが公共交通オープンデータセンターの[データセットのページ](https://ckan.odpt.org/dataset/hakodate_city_alllines)から最新のものを探します。
作り直したら、`data/network.js` の函館市電の便数や時刻が変わっていることを確かめてください（今のデータは 2026 年 8 月 15 日〜2027 年 8 月 14 日のダイヤ）。

### 運行シミュレーションの仕組み

各系統について「運転間隔・運転時間帯・停車駅・最高速度・停車時間」を定め、
始発駅の発車時刻から各駅の発着時刻を計算し、駅間は加速→巡航→減速の台形速度で補間しています。
時刻から位置が決定的に決まるので、サーバは不要です。

## 現状の制約 (プロトタイプ)

- **函館市電は、公開されている時刻表データ（GTFS）で走ります**（平日／土休日ダイヤを日付で自動切り替え）。
- **都市間高速バスも、時刻表データ（GTFS）で走ります。** 路線バスは地図上では動かさず、停留所の時刻表だけを表示します。
- **それ以外の列車・船・飛行機の位置は、実際の運行ではありません。** 制作者が決めた運転間隔・便数からの推計で、個々の発車時刻は実際の時刻表と一致しません。平日・土休日の区別もありません。札幌市交通局・JR 北海道などの時刻表データは、2026 年 9 月時点で公開を確認できませんでした。
- 駅の並びは駅データ.jp（数年前の時点）をもとに、国土数値情報（2024 年度）に無い JR の駅（廃止駅）を除き、改称（当別・太美・名寄高校）と新駅（ロイズタウン）を反映しています。廃止された区間（石勝線 夕張支線、札沼線 北海道医療大学〜新十津川、日高本線 鵡川〜様似、留萌本線、根室本線 富良野〜新得）は含めていません。2025 年以降の駅の廃止・新設は反映していない場合があります。
- 北海道新幹線は新函館北斗〜新青森のみを表示しています（新青森から先へ向かう列車は新青森で消えます）。
- 長距離フェリー（大洗・仙台・新潟・舞鶴方面）は、北海道の沖合で現れ・消えます。航路の形は概略です。
- 列車は終点に着くと 1〜2 分停車したあと消えます（到着列車がそのまま折り返す運用は再現していません）。

## 今後の発展案

1. **実ダイヤ化**: 札幌市交通局・JR 北海道などの GTFS / GTFS-JP が公開されたら取り込み、推計ダイヤを実時刻表に置き換える（奥尻〜江差フェリーは公共交通オープンデータセンターの利用者登録をすれば取り込める）
   (Mini Tokyo 3D にも [GTFS プラグイン](https://www.npmjs.com/package/mt3d-plugin-gtfs) があります)。
2. **路線バスの時刻表**: 函館バス・JR 北海道バスなどの時刻表データが公開されたら取り込む
