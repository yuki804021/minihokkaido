# Mini Hokkaido 3D

[Mini Tokyo 3D](https://minitokyo3d.com/) を参考にした、**札幌を中心とした北海道の鉄道の 3D 可視化**のプロトタイプです。
3D 地図の上を列車が時刻に合わせて走ります。

[Mini Shikoku 3D](https://github.com/marui-takeru/minishikoku3d)（四国版）をもとに、地図の範囲と路線データを北海道に入れ替えたものです。

- 札幌市営地下鉄（南北線・東西線・東豊線）、札幌市電（ループ線の外回り・内回り）、函館市電（2 系統・5 系統）
- JR 北海道の普通・快速（快速エアポート、はこだてライナーなど）と主な特急（北斗、すずらん、ライラック・カムイ、宗谷、サロベツ、オホーツク、大雪、おおぞら、とかち）
- 北海道新幹線 はやぶさ（新函館北斗〜新青森）、道南いさりび鉄道
- 主なフェリー（津軽海峡フェリー・青函フェリー、シルバーフェリー、さんふらわあ・太平洋フェリー、新日本海フェリー、ハートランドフェリー、羽幌沿海フェリー）
- 道内 12 空港と航空便（推計）。道外便のほか、丘珠・新千歳などを結ぶ道内便は離陸から着陸まで 1 本の経路で飛ぶ

## 使い方

ビルドは不要です。静的サーバで配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages などの静的ホスティングにそのまま置けます。

| 操作 | 内容 |
| --- | --- |
| 列車をクリック | 系統・行先と、この先の停車駅・到着予定の一覧を表示。「追跡」でカメラが追従 |
| 駅をクリック | その駅の発車案内（この先の発車時刻・系統・行先）を表示 |
| 駅をさがす | 駅名を入力するとその駅へ移動し、発車案内を表示 |
| 空港をクリック | 滑走路・運用時間・就航先（推計）と、まもなく出発／到着する便 |
| 到達圏 | 発車案内の「ここから行ける範囲（到達圏）を表示」で、その時刻に出発して各駅へ最短何分で着けるかを 5 段階で色分け表示。上限は 30/60/90 分から選択でき、「今の時刻で再計算」で時間帯ごとの比較ができる |
| 実時間 / ×10 / ×60 / ×300 | 時間の進み方を変更 |
| 時刻入力 | 任意の時刻へジャンプ (例: 朝ラッシュ 07:45) |
| エリア | 札幌中心部・すすきの・札幌近郊・新千歳空港・小樽・旭川・函館・釧路・津軽海峡・稚内／利尻／礼文・北海道全体へ移動 |
| 路線 | 事業者・種別ごとの表示切り替え |
| 1日の運行本数 | 表示中の路線について、時刻ごとの運行中の列車本数をグラフ表示。ホバーで値、クリックでその時刻へ移動。「表で見る」で 1 時間ごとの表 |
| 表示 | 地図の昼夜（自動・ライト・ダーク）、3D 建物、地形 (標高) |
| 撮影モード | パネルを隠してカメラをゆっくり回転（動画・GIF 撮影用）。Esc で終了。`?cinema` でも起動 |
| この景色を共有 | 今の時刻・倍速・カメラ位置を含むリンクをコピー |
| キー操作 | Space 一時停止、1〜4 倍速、N 現在時刻、C 撮影モード、F 追跡、Esc 閉じる |

URL パラメータ: `?t=07:45` (開始時刻), `?speed=60`, `?view=hakodate`, `?theme=light` / `?theme=dark` (昼夜の自動切り替えを止める), `?terrain`

`?view=` に使える値: `sapporo` `susukino` `sapporo_wide` `new_chitose` `otaru` `asahikawa` `hakodate` `kushiro` `seikan` `wakkanai` `hokkaido`

## 構成

```
index.html              画面
css/style.css
js/sim.js               運行シミュレーション (時刻 → 列車位置)
js/app.js               地図・描画・UI (MapLibre GL JS)
data/network.js         路線・駅・運行パターン (自動生成)
tools/build_network.py  data/network.js を作るスクリプト
```

- 地図: [MapLibre GL JS](https://maplibre.org/) + [OpenFreeMap](https://openfreemap.org/) (OpenStreetMap ベース、API キー不要)。
  読み込めない場合は国土地理院の淡色地図に切り替わります。
- 地形: AWS Terrain Tiles (Terrarium)
- 列車は `fill-extrusion` で車体・窓・屋根を積み重ねて描画し、ズームアウト時は見やすいよう大きさを誇張しています。
- 光の向きと空の色は、シミュレーション時刻の太陽の位置（札幌付近）に合わせて朝・昼・夕・夜と変化します。
- 始発駅では発車の数分前から列車がホームで待機します。
- 日没後は地図が夜のデザインに切り替わり、列車の前照灯と尾灯が灯ります（「地図: 自動（昼夜）」のとき）。

使っているデータの一覧と、実データ・推計の区別は [DATA_SOURCES.md](DATA_SOURCES.md) に、更新履歴は [CHANGELOG.md](CHANGELOG.md) にまとめています。

### 路線データの作り直し

路線・運転間隔・停車駅・フェリー・空港の設定は `tools/build_network.py` にまとめてあります。編集したら次のコマンドで `data/network.js` を作り直します。

```sh
python3 tools/build_network.py
```

初回は駅データ（駅データ.jp、GitHub 経由）と国土数値情報（鉄道データ、約 13MB）をダウンロードして `tools/cache/` に保存します。
駅の位置はそれぞれ国土数値情報の駅（ホームの中点）に合わせ、駅と駅の間は国土数値情報の線路網の最短経路でつないでいます（路線の長さは営業キロとほぼ一致します）。

### 運行シミュレーションの仕組み

各系統について「運転間隔・運転時間帯・停車駅・最高速度・停車時間」を定め、
始発駅の発車時刻から各駅の発着時刻を計算し、駅間は加速→巡航→減速の台形速度で補間しています。
時刻から位置が決定的に決まるので、サーバは不要です。

## 現状の制約 (プロトタイプ)

- **列車・船・飛行機の位置は、実際の運行ではありません。** すべて制作者が決めた運転間隔・便数からの推計で、個々の発車時刻は実際の時刻表と一致しません。平日・土休日の区別もありません。
- 駅の並びは駅データ.jp（数年前の時点）をもとに、国土数値情報（2024 年度）に無い JR の駅（廃止駅）を除き、改称（当別・太美・名寄高校）と新駅（ロイズタウン）を反映しています。廃止された区間（石勝線 夕張支線、札沼線 北海道医療大学〜新十津川、日高本線 鵡川〜様似、留萌本線、根室本線 富良野〜新得）は含めていません。2025 年以降の駅の廃止・新設は反映していない場合があります。
- 北海道新幹線は新函館北斗〜新青森のみを表示しています（新青森から先へ向かう列車は新青森で消えます）。
- 長距離フェリー（大洗・仙台・新潟・舞鶴方面）は、北海道の沖合で現れ・消えます。航路の形は概略です。
- 空港の位置・滑走路の向きは概略で、利用統計は未収録です。
- 列車は終点に着くと 1〜2 分停車したあと消えます（到着列車がそのまま折り返す運用は再現していません）。

## 今後の発展案

1. **実ダイヤ化**: 札幌市交通局などが公開する GTFS / GTFS-JP を取り込み、推計ダイヤを実時刻表に置き換える
   (Mini Tokyo 3D にも [GTFS プラグイン](https://www.npmjs.com/package/mt3d-plugin-gtfs) があります)。
2. **空港の利用状況**: 国土交通省「空港管理状況調書」の乗降客数・着陸回数を取り込み、四国版と同じグラフを表示する
3. **バス**: 札幌の路線バス、都市間バスなど
