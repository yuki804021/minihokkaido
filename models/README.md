# 車両の 3D 模型

地図に車両の 3D 模型を置くための、車種ごとの模型（glTF バイナリ `.glb`）です。
いまは `tools/models/build_models.py` で、寸法と塗装の設定から自動で作った**簡易模型**です。
地図への組み込み（Three.js を使った独自レイヤー）はこれからで、まだアプリには表示されません。

| ファイル | 車両 | 三角形 |
| --- | --- | --- |
| `kiha261_lead.glb` | キハ261系1000番台（新塗装）先頭車 | 544 |
| `kiha261_mid.glb` | キハ261系1000番台（新塗装）中間車 | 376 |
| `ser733_lead.glb` | 733系（札幌圏）先頭車 | 628 |
| `ser733_mid.glb` | 733系（札幌圏）中間車（パンタグラフ付き） | 448 |

`manifest.json` に、ファイル名・名前・車体の長さ・三角形の数をまとめています。

## 見てみる

サーバー（`python tools/serve.py`）を起動して、`http://localhost:8000/models/viewer.html` を開きます。
1 両ずつと 3 両編成を切り替えられ、ドラッグで回転、ホイールで拡大・縮小できます。

## 模型の決まり

アプリ側はどの車種も同じ処理で地図に置くので、次をそろえてください。

- **単位はメートル**（Blender の 1 単位 = 1m）。車体長・幅・高さは実物どおり
- **前が +Z**（glTF の座標。Blender では -Y 方向が前になります。書き出し時に「+Y を上」にすると変換されます）。先頭車は運転台を前に向ける
- **原点は車体の中心・レールの高さ**（床下の台車の下端が高さ 0 付近）
- **1 両ずつ**。編成はアプリ側で並べ、後ろ向きの先頭車は 180 度回して使う
- **軽く**: 1 両あたり三角形 2,000 個以下を目安に。窓や帯は形を彫らず、色を分けた面で表す
- **色はマテリアルで**: 画像（テクスチャ）は使わず、部位ごとに色を分ける。同じ形で色だけ違う車種は、同じ模型をアプリ側で塗り分ける予定

## 形や色を変える

### 設定を変えて作り直す（かんたん）

`tools/models/build_models.py` の `CARS` に、車種ごとの寸法・色・窓や帯の高さ・扉の位置があります。
値を変えてから、次で作り直します。

```sh
python tools/models/build_models.py
```

色は `[赤, 緑, 青]`（0〜1）と、金属らしさ（0〜1）・ざらつき（0〜1）の組です。

### Blender で作り込む（本格的に）

1. [Blender](https://www.blender.org/)（無料）を入れる
2. 「ファイル → インポート → glTF 2.0」で、作り込みたい `.glb` を読み込む（自動で作った模型を土台にできる）
3. 形を整える。よく使う操作:
   - `Tab` で編集モード、`1` / `2` / `3` で頂点・辺・面の選択
   - `G` 移動、`S` 拡大縮小、`R` 回転、`E` 押し出し、`Ctrl + B` 角を丸める（ベベル）
   - 窓・帯は面を選んで、別のマテリアル（色）を割り当てる
4. 仕上げ: 全体を選んで `Ctrl + A` →「すべてのトランスフォーム」を適用。原点が車体中心・レール高さにあることを確認
5. 「ファイル → エクスポート → glTF 2.0」で、形式「glTF バイナリ (.glb)」、「+Y を上」にチェックして、**同じファイル名で上書き**
6. `viewer.html` で向き・大きさ・色を確認

自分で作り込んだ模型は、`build_models.py` を実行すると上書きされてしまいます。
作り込んだ車種は `CARS` から外すか、別のファイル名で保存して `manifest.json` を書き換えてください。
